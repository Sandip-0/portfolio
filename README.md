# Personal Portfolio

A modern and responsive personal portfolio website built with **React.js** to showcase my skills, projects, education, certifications, and professional profile.

## Live Demo

**Portfolio:** https://sandip-0.github.io/portfolio/

This portfolio website provides an overview of my background as a **Computer Science & Engineering student** and my interests in **Data Science, Machine Learning, and Software Development**.

It includes sections for:

* About Me
* Technical Skills
* Projects
* Education
* Certifications
* Contact Information

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Sandip-0/portfolio.git
```

### 2. Navigate to the project directory

```bash
cd portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm start
```

The application will run locally at:

```text
http://localhost:3000
```

## Build for Production

```bash
npm run build
```

This creates an optimized production build of the application.
