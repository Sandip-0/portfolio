1. HOW TO ADD OR EDIT PROJECTS
================================================================================
File Location: src/data/projects.js

To edit an existing project:
- Open "src/data/projects.js"
- Find the project you want to change (e.g. "insightforge-rag" or "credit-risk-prediction")
- Edit the title, overview, techStack, githubUrl, or liveUrl.

To ADD a brand new project:
- Open "src/data/projects.js"
- Copy and paste this block into the "projects" list:

  {
    id: "my-new-project",
    title: "Project Title Here",
    tagline: "Short one-line subtitle",
    category: "ai",             // Choose one: "ai" | "ml" | "web"
    featured: false,           // Set true to make it a large featured card
    badge: "Computer Vision",
    techStack: ["Python", "PyTorch", "Streamlit"],
    overview: "Detailed description of what this project does.",
    bulletPoints: [
      "Key achievement or feature 1",
      "Key achievement or feature 2"
    ],
    keyMetrics: [
      { label: "Accuracy", value: "95%" },
      { label: "Deployment", value: "Streamlit Cloud" }
    ],
    githubUrl: "https://github.com/Sandip-0/your-repo-name",
    liveUrl: "https://your-app.streamlit.app", // or null if no live link
    color: "from-cyan-500/20 via-blue-500/10 to-transparent",
    accentColor: "#06b6d4"
  },

Save the file, and your new project will appear on the website immediately!

3. HOW TO REPLACE YOUR PDF RESUME FILE
================================================================================
Location: public/resume.pdf

Whenever you have a new PDF resume:
1. Save or rename your PDF file to: "resume.pdf"
2. Copy it into the "public/" folder:
   sandip-portfolio/public/resume.pdf
3. That's it! The "Download Resume" buttons on the website will automatically
   download this updated PDF file.

6. HOW TO DEPLOY YOUR WEBSITE LIVE
================================================================================

OPTION A: DEPLOY TO VERCEL (EASIEST & RECOMMENDED)
1. Push your repository to GitHub:
   cd /Users/sandipadak/.gemini/antigravity/scratch/sandip-portfolio
   git init
   git add .
   git commit -m "Updated portfolio"
   git remote add origin https://github.com/Sandip-0/portfolio.git
   git branch -M main
   git push -u origin main --force

2. Go to https://vercel.com and log in with your GitHub.
3. Click "Add New Project" and choose your "portfolio" repository.
4. Click "Deploy". Your site is live in 30 seconds!

---

OPTION B: DEPLOY TO GITHUB PAGES (https://sandip-0.github.io/portfolio/)
1. In "vite.config.js", make sure you have:
   base: '/portfolio/',

2. Run:
   npm install --save-dev gh-pages

3. In "package.json", add:
   "scripts": {
     "predeploy": "npm run build",
     "deploy": "gh-pages -d dist"
   }

4. Run:
   npm run deploy
